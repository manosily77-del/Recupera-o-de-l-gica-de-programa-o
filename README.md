# Sistema de Cadastro de Medicamentos

## Descrição

Este projeto é um sistema simples de cadastro de medicamentos desenvolvido em Python.

O programa simula um cadastro básico de uma farmácia, permitindo cadastrar medicamentos, listar os medicamentos cadastrados e buscar um medicamento pelo nome.

Os dados são armazenados no arquivo "medicamentos.csv", permitindo que os medicamentos continuem salvos mesmo depois que o programa for encerrado.

## Como executar

1. Baixe ou clone o repositório.
2. Abra a pasta do projeto.
3. Execute o arquivo "main.py" pelo terminal.
